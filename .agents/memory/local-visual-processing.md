---
name: Local visual processing
description: Privacy boundary for EMOTION / SYSTEM camera and computer-vision features.
---

Process webcam frames, person tracks, face landmarks, expression estimates, and visual effects only in the visitor's browser; never upload or server-persist them. The Deviation ID page must never require login. The user wants an explicit opt-in for sending profile data and photos to the event dataset, so do not enable that upload until a compatible anonymous backend endpoint is available; never present a no-op as a successful upload. Sequential subject numbers are per-browser unless a future anonymous backend provides a global sequence. The user explicitly wants photos and recordings to be generated and downloaded locally from the visible browser tab, including visible effects and information panels, after an explicit capture action. Fullscreen photos must capture the in-page preview locally without opening a browser screen-share picker or leaving fullscreen.

**Why:** The user requires browser-local processing and no transmission of camera data, explicitly requests local downloads of the rendered screen, and clarified that the site must not require login even when opting into event data collection. A browser-only sequence cannot be described as a global site order. For screenshot image-ratio issues, they specifically asked to leave panel widths unchanged.

**How to apply:** Keep camera, AI, rendering, and Deviation ID profile/photo storage client-side by default; do not add server calls for frames, landmarks, or derived biometric data. Keep any profile/photo contribution explicitly opt-in and use a supported anonymous endpoint before enabling it. Store the local subject counter in IndexedDB and label it device-only. Ask for screen capture only from a user-initiated capture button and save the result locally. In fullscreen, capture the preview and its visible effect/HUD layers in-page instead of requesting display capture. Preserve live HUD panel widths; fix screenshot-only image sizing in the cloned capture.
